## ML Feasibility and Problem Selection

**Project:** PurjeStore Intelligent E-Commerce Analytics & Decision Support System

---

## 1. Purpose and Scope

Major Milestone 6 evaluated whether the evidence established by the completed PurjeStore analytical and EDA foundation supports one or more defensible machine-learning problems.

The milestone covered:

- candidate target evaluation;
- feature and predictor availability review;
- data-volume assessment;
- temporal and event-timing validity;
- leakage-risk review;
- prediction-event and target formulation;
- evaluation-design feasibility;
- evidence resolution for candidates requiring additional evidence;
- final ML problem-selection gating.

The milestone did not authorize model training, modeling feature engineering, broad relational joins, deduplication, source modification, analytical-source modification, causal inference, or unsupported business-impact claims.

The governing decision rule was evidence-based: an ML problem could advance only when its prediction event, target meaning, information-availability boundary, leakage controls, and evaluation design were sufficiently defensible.

## 7. Final ML Selection Decision

### Selected ML problems: 0

No current candidate satisfied the evidence threshold required for promotion into the final ML problem-selection set.

The decisive unresolved requirements were:

1. a clearly defined prediction event;
2. a target whose semantic meaning is appropriate for prediction;
3. a defensible information-availability boundary;
4. prevention of post-event leakage;
5. a valid feature-availability definition;
6. an appropriate evaluation design;
7. sufficient evidence to justify the prediction task from the actual PurjeStore data.

Therefore:

> **No ML problem is currently supported strongly enough to proceed to model training.**

This is an evidence-preservation decision, not a claim that machine learning can never be applied to PurjeStore.

The project does not force an ML model merely because ML appears in the overall project roadmap.
